# 复利计算器 · 课程作业

## 项目名称

lesson01 — 复利计算器（含复利与单利对比、增长曲线可视化）

## 作业目的

使用 AI 辅助开发一个复利计算程序，在实践中：

- 掌握复利与单利的计算方法；
- 体验“明确指令”与“模糊指令”对 AI 生成结果可控性的影响；
- 经历从命令行到图形界面、从纯计算到可视化的迭代开发过程。

## 项目功能

- 用户输入本金与年利率（百分数，如输入 5 表示 5%）；
- 输入校验：本金必须大于 0，年利率不能为负数；
- 计算 10、20、30 年的复利终值、单利终值及差额，以表格展示；
- GUI 版额外绘制 0～30 年复利与单利增长曲线，直观对比两者增长差异。

## 公式说明

- 复利终值：`A = P × (1 + r) ^ n`
  - 利息每年滚入本金，下一年的利息按新本金计算。
- 单利终值：`A = P × (1 + r × n)`
  - 利息只按最初本金计算，不滚存。

其中 `P` 为本金、`r` 为年利率（小数）、`n` 为年数。

## 运行方法

```bash

python compound_interest.py

# 图形界面版
python compound_interest_gui.py

# 模糊指令实验版

```

## 测试示例

输入本金 `10000`、年利率 `5`，结果如下：

| 年数 | 复利终值（元） | 单利终值（元） | 差额（元） |
| --- | --- | --- | --- |
| 10 | 16288.95 | 15000.00 | 1288.95 |
| 20 | 26532.98 | 20000.00 | 6532.98 |
| 30 | 43219.42 | 25000.00 | 18219.42 |

可见随年限增加，复利（指数增长）与单利（线性增长）的差距逐渐扩大。

## AI 辅助开发过程概述

借助 AI 工具分四阶段迭代完成：

1. **基础版**：按明确指令生成固定参数（本金 10000、年利率 5%、3 年）的复利计算程序。
2. **交互版**：升级为用户输入本金与年利率，增加输入校验。
3. **复利/单利对比**：增加 10/20/30 年对比表格。
4. **可视化**：引入 matplotlib 绘制 0～30 年增长曲线。

过程中对比了提问方式的影响：**明确指令**（指定公式、参数、文件名）使 AI 生成结果与需求一致；**模糊指令**（“写个复利计算器”）导致 AI 自行增加交互输入与复利次数等设计，结果需要事后核对。详见 `progress.md`。
